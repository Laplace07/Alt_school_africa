# FullStack Engineering Assessment

This repository contains my FullStack Engineering assessment work, consisting of 2 HTML assignments and 5 JavaScript problems.

## HTML Assignments

- HTML Assignment 1: Create Account Form
- HTML Assignment 2: Semantic HTML and Accessibility Practice

## JavaScript Assignments

1. Deep Equal – Recursively compares objects, including nested objects.
2. Object Diff – Identifies added, removed, and changed top-level properties.
3. Deep Freeze – Recursively freezes objects and their nested objects.
4. Private Counter Factory – Uses closures and getters to create a private counter.
5. Schema Validator – Validates object properties against expected data types.
